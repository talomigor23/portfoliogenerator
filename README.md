 Automatiser la création des portfolios
 interface intuitive qui propose des templates issus de plusieurs modèles "les plus populaires"
 Formulaire remplissable avec la possibilité de voir directement l'aperçu
 Présence d'animation, personnalisation accrue.

 Fichier téléchargé : votrenom.html que l'utilisateur pourra déploier plustard sur des plateformes comme github, vercel ou netlifly
